# Try these

## 1. The rendered 2D anime clip

Open [`demo/hina-walking-talking.mp4`](demo/hina-walking-talking.mp4).

Hina walks in, stops, and speaks. The voice is Piper TTS; the mouth is driven by
Rhubarb Lip Sync cues.

Render specs: 1920×1080, 24 fps, 9.3 s, H.264 + AAC.

## 2. The interactive voice demo

Open [`voice/demo/index.html`](voice/demo/index.html) and press **Play voice**.

The audio is embedded, so this works offline. The page shows the current mouth
shape while the character speaks.

## 3. The anime-cel source project

```text
voice/anime-demo/
```

Rebuild it:

```powershell
cd voice/anime-demo
npm install
node render.mjs --frames --workers=4
node render.mjs --encode --out=out/video.mp4 --audio=assets/voice.wav
```

The scene is in `src/scenes/voice.js`. The mouth track is in `src/mouth.js`,
generated by `make_mouth.py` from Rhubarb JSON.

## 4. Generate a new voice line

```powershell
cd voice
python tts_lipsync.py "Your new line here" --out demo/line1
```

Outputs `demo/line1.wav` and `demo/line1.json`.

Tagalog/Filipino:

```powershell
python tts_lipsync.py "Kumusta! Ako si Hina." --out demo/line1 --phonetic
```

The included Piper voice is English; use a Filipino voice for natural Tagalog.

## 5. The full ReelMimic app

If ReelMimic is installed at the repo root:

```powershell
cd reelmimic
start.bat
```

Open <http://localhost:4318>.

ReelMimic needs Claude Code or Codex. It uses your account's usage. A 30–60 s
film takes roughly 1–3.5 hours.

## 6. Toonflow reference

Toonflow is not vendored. Clone it if you want to compare script-to-video:

```powershell
git clone --depth 1 https://github.com/HBAI-Ltd/Toonflow-app.git toonflow
```

It is a script → storyboard → AI video/short-drama platform. It is not true
frame-by-frame 2D animation.
