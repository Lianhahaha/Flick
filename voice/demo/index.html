This is a real 2D character driven by a local voice and a lip-sync track. No cloud, no API key.

Hina: “Hi! I’m Hina. I can walk, talk, and act in a 2D cartoon. This voice is generated on your computer, and my mouth is synced with Rhubarb Lip Sync.”

Piper TTS (MIT) generates the voice locally. Rhubarb Lip Sync (MIT) turns the audio into 8 mouth shapes. This is the same voice + viseme pipeline wired into ReelMimic’s anime-cel engine.
